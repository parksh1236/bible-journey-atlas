# 말씀의 여정 · Bible Journey Atlas

성경 인물의 이동 경로와 사건, 성경 구절, 고대 지역의 배경과 오늘날의 모습을 함께 살펴보는 한국어 웹페이지입니다.

[운영 중인 웹페이지](https://bible-journey-atlas-1111.parksh1236.chatgpt.site) · 기존 배포 사이트는 로그인 및 소유자 접근 설정이 적용되어 있습니다. 이 저장소 공개와 웹사이트 접근 설정은 별개입니다.

## 수록 내용

- 아브라함·모세·여호수아·예수님·바울의 주요 사건 38개
- 장소의 사건 55개: 아브라함·모세·여호수아·예수님·바울의 전투와 이적과 말씀을 일러스트 모션그래픽으로 재생 (지도의 ‘장소의 사건’ 핀 또는 카드)
- 34개 지역의 역사·지리 설명, 현대 지명, 사진 또는 위성 영상
- 성경 미술 26점과 사건 흐름도
- 인물·주제별 탐색, 지도 선택, 순차 재생과 확대 보기
- 대표 좌표 기준 직선거리와 연결선 거리 합계
- 모바일 레이아웃과 이미지 확대 보기

## 실행

HTML·CSS·JavaScript로 작성된 정적 웹사이트로 별도 빌드나 API 키가 필요하지 않습니다.

```bash
git clone https://github.com/parksh1236/bible-journey-atlas.git
cd bible-journey-atlas
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 여세요. `dist/` 폴더를 정적 웹 호스팅의 게시 디렉터리로 사용할 수도 있습니다. 웹폰트와 외부 성경·자료 링크에는 인터넷 연결이 필요합니다.

## 3D 지도 조작

- 드래그: 회전 · Shift+드래그(또는 오른쪽 드래그): 이동 · ⌘/Ctrl+스크롤 또는 두 손가락: 확대·축소
- 지형 높이는 실제보다 과장해 표시하며, 해안선은 현대 고도 자료 기준입니다.
- `prefers-reduced-motion`을 켠 사용자에게는 카메라 비행과 애니메이션을 생략합니다.
- 지형 데이터를 다시 만들려면 `python3 tools/build_terrain.py` (numpy·Pillow 필요)

## 자료를 읽을 때

지도는 학습용 개략도이며 실제 고대 도로·항로를 복원하지 않습니다. 거리는 대표 좌표 사이의 대권거리로 실제 이동거리와 다릅니다. 위치가 논쟁 중인 장소는 후보지·전승지 또는 주변 경관을 표시합니다.

사진은 촬영 당시의 기록입니다. 성경 미술은 후대의 해석이며 사건을 촬영한 사진이나 고증 복원도가 아닙니다. 예수님의 여정은 요한복음의 주요 장소를 선별한 것이며, 바울은 첫 번째 선교여행을 다룹니다. 성경 설명은 요약으로 제공하며 본문 전문은 대한성서공회 페이지에서 찾아 읽도록 연결합니다.

## 이미지와 이용 조건

각 이미지의 저작자·원본·라이선스는 화면과 [CREDITS.md](CREDITS.md)에 표시했습니다. 공개 저장소라는 사실이 모든 이미지에 같은 라이선스를 부여하지는 않습니다. 재사용할 때 각 자료의 조건을 확인하세요. 프로젝트 코드에 별도의 오픈소스 라이선스를 지정하지 않았습니다.
